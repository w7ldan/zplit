# Zplit

Zplit is a self-hostable personal expense and repayment tracker.

## Current checkpoint

This checkpoint contains the frontend and development foundation only. Database, authentication, and deployment are not implemented yet.

## Prerequisites

- Node.js 20.9+
- npm 10+

## Commands

```sh
npm install
npm run dev
npm run typecheck
npm test
npm run lint
npm run build
```
